# 灵动岛章节导航

浮在画面上的一枚胶囊，告诉观众现在在哪一章、这一章走到哪。不是一条顶栏，也不是纸带。

和 `scripts/navbar.py` 的纸带导航并行，不替换它。纸带是独立一条视频轨；这枚岛是叠在成片画面上的一层。

## 布局契约

写死，不随配色变。

| 位置 | 内容 | 规则 |
|---|---|---|
| 左 | 当前章节名 | 全真章节名。禁止「开场 / 爆点 / 钩子 / 高潮 / 金句 / 干货 / 必看 / 揭秘 / 反转」。渲染器遇到这些词直接报错 |
| 右 | `03/07` | 两位序号，字号小于章名，颜色比章名淡一档 |
| 章名下方 | 细进度条 | **本章内**进度，不是全片进度。长度跟章名走，右端停在序号之前 |

字只有两档：章名 Bold，序号 Regular。进度条不是第三档字。

## 几何（相对 1080 宽，随帧宽等比缩放）

| 项 | 1080 宽时 |
|---|---|
| 左右边距 | 帧宽的 5.56%（60px） |
| 距顶 | 28px |
| 岛高 | 118px，圆角 59px，两端是半圆 |
| 左右内边距 | 44px |
| 章名字号 | 42px |
| 序号字号 | 30px，比章名下移 8px 对齐视觉中线 |
| 进度条 | 高 4px，距章名下沿 8px，最长 360px |
| 下移偏层 | 同形胶囊下移 7px，alpha 42，不模糊 |

比 1080 宽或窄的帧按 `帧宽 / 1080` 缩放全部 px 值。

## 层级（从底到顶，全部裁在胶囊内）

1. 取样岛下那一块画面，只模糊这一块。
2. 铺一层半透明玻璃色。
3. 内部纵向渐变：上亮、下沉。
4. 下移偏层，同轮廓，不外扩。
5. 沿上沿内侧一条高光，跟着圆角走，两端淡出。
6. 1px 内描边，贴着胶囊边缘。
7. 章名、序号、进度条。

**岛外什么都不做。** 不加雾化、光晕、暗角、弥散投影。旧 mock 把整条顶带磨掉，是被否掉的做法。

## 配色

每个 preset 四个角色：玻璃、墨色（章名/序号）、口音（进度）、发丝（描边/高光）。不许再加一档。

| id | 名 | 锚点 | 用在 | 别用在 |
|---|---|---|---|---|
| ink | 墨岛 | A | 浅底、亮墙 | 深底，对比会塌 |
| milk | 奶玻璃 | B | 深底、夜景 | 浅墙，会融进去 |
| forest | 森绿 | | 浅底、暖室内 | 深底偏沉 |
| sand | 暖沙 | | 深底、冷画面 | 暖色浅底 |
| slate | 石板 | | 花背景、明暗不一 | 和 forest 混用，口音冲突 |
| paper | 纸白 | | 深底、要最高可读性 | 浅底，变成白牌子；玻璃感也最弱 |

G6 这组画面顶半是亮墙，默认用 **ink**。milk 在这组亮墙上偏淡，留着给深底镜头。

## 烧进去走哪条

**PNG 序列叠层，不走 ASS。**

ASS 画不出这块玻璃。圆角、内模糊、上沿高光、内描边都要逐帧算，libass 没有这些。硬用 ASS 只能得到一块纯色圆角矩形，玻璃感没了。

做法：按成片帧率把每一帧的岛渲染成透明 PNG，ffmpeg `overlay` 一次叠上。岛的位置和形状整段不变，变的只有章名、序号和进度，所以不用每帧重算模糊——章切换时重绘一次文字层即可。这是 Stage B 的事，本工具只提供 `render_island()`。

纸带导航（`navbar.py`）继续作为独立轨的选项，不从这里调用。

## 调用

```bash
python3 island_nav.py --bases frame.png --colorway ink \
  --chapter 被社会做局生孩子 --idx 3 --total 7 --frac 0.4 --out out.png
```

不给 `--colorway` 就渲染全部 preset。需要 Pillow。
