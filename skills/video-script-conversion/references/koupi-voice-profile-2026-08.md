# Liz 口癖语料库 & 口播修整细则

定版：2026-08-02。来源：Liz 重录口播后自察口癖 + 两路 AI 精读（A：逻辑算子 / 序列化诊断；B：隐藏口癖 / 检验句 / 解码成本工序）。原始讨论全档：`references/koupi-raw-discussion-2026-08.md`。本文件是「修整 / 实录修整」模式的口癖执行细则与反 slop 判定依据。

## 1. Liz 的口癖不是 filler，是逻辑算子

普通人口癖是**排泄型**（嗯/那个/然后——无思维功能）；Liz 的口癖几乎全是**操作型**——每个词执行一个逻辑运算，是她的思维结构本身：

| Liz 口癖 | 实际运算 |
|---|---|
| 首先 / 另外 / 且 / 另外就是 | 枚举、建栈 |
| 比如说 | 实例化（抽象→具体） |
| 也就是说 / 换句话说 / 换言之 | 等价重述、二次编码 |
| 反过来说 / 反过来看 / 倒过来 / 换个角度 | 坐标系旋转 |
| 严格来说 / 这不是说 / 这并不意味着 | 边界划定、排除误读 |
| 因为/所以/虽然/但是 | 显式标注因果与让步 |
| 可能 / 或者说 / 某种程度上 | 概率对冲 |

**双诊补充（Liz 未自察的隐藏组）**：
- **「其实」= 真·首发词**：频率压过「首先」，功能是「我要说更接近真相的版本了」的开机自检。
- **「也就是说」= 重编码癖**：每输出一个命题立刻同义改写——思想发一次，传输发两次。
- **对冲三连**：「可能是因为我的表达过于精密（这算是在自夸吗？）但它真的是为了复杂而复杂吗？」——可能 + 元认知自问 + 反问，链式叠在一句。
- **元认知弹窗**：「你可以想象一下」「看到了吗？🤣」「这算是在自夸吗」——传输内容时持续监控接收方状态。**活人感组件，修整时一个都别删。**
- **法律级精确词入侵日常语**：「包括但不限于」「信息传输协议」——合同/协议语言，是「云里雾里」感的主要来源。
- **堆近义词**：「直接、简洁、朴素、高效、清爽、流畅、丝滑」——不满足于一个词，用一组近义词逼近精确。最底层思维习惯，也是「过于精密」的来源。
- **括号癖 / 标点癖**：比常人更频繁用括号与标点分层——表达底层是「书写态」。

## 2. 诊断：问题不是复杂，是序列化

- 思想是图（graph），语言是流（stream）；说话 = 把图序列化成流。
- Liz 的困境：序列化时**把遍历过程也发送了出去**——每走一步报边界条件（严格来说）、回溯一次（反过来说）、标注置信度（可能）。**信息没有冗余，路径全是冗余。**
- 接收方要的是拓扑排序：先主干节点，再分支。
- **括号是写作者的免费工具，在音频里很贵——音频没有后退键**。口播里括号 + 回跳指代（前者后者）= 迷路。
- 「时代所趋、人们不擅长语言」是浪漫化判断；真相是**编码精度超过信道额定带宽 = 协议不匹配**，缺的是协议转换层（= 本 skill 的修整动作）。

## 3. 执行规则（模式②修整 / 模式③实录修整）

**删（排泄型，无信息）**：嗯 / 啊 / 那个 / 就是 / 无功能「然后」。

**留（操作型 + 活人指纹）**：
- 逻辑算子（首先/比如说/也就是说/严格来说/反过来说…）——思维结构，删了就不是 Liz；
- 元认知弹窗（看到了吗/这算是在自夸吗）——活人指纹，AI 时代最稀缺；
- 句子级口语节奏词（说白了/这话听着像废话，但是是真的）；
- 金句与真实细节。

**剪（口播态序列化专项 = 「解码成本审查」工序；改语言层，不重构）**：
1. 堆近义词只留一个（丝滑/清爽/流畅 → 挑最口语那个）；
2. 括号内容展平：并进主句或删掉；回跳指代（前者后者）换顺流表达；
3. 对冲链最多一层：「可能」和「或者说」留一个；三连对冲 = 让接收方以为你自己没想清楚；
4. 名词化改动词化：「不同主体之间需要使用不同的信息传输协议」→「见人说人话，见 AI 说 AI 话」。口诀：**把名词换成动词，把概念换成场景，把「人」字放回句子里**；
5. 一次一个隐喻，用完即弃（虚拟机/协议/信道/编译器套娃 = 认知税）；
6. 长句拆短句。

**工序原则**：精密度移到草稿阶段，简洁度留给成稿/口播阶段——先按 Liz 原样把话说透，再做解码成本审查。**不降信息密度，只降解码成本。**

## 4. 高质量口癖清单（Liz 自我习得参考——不进口播稿）

- **引擎型（疑问句算子，生成思维）**：代价是什么？（机会成本）/ 反例是什么？（证伪）/ 在什么意义上？（消歧）/ 到什么程度？（剂量思维）/ 所以呢？那又怎样？（so-what）/ 十年后还成立吗？（时间轴拉伸）。
- **精化型**：具体来说（强制落地）/ 取决于（条件化思维）/ 大概率（诚实概率声明）。
- **传输协议型**：先说结论（BLUF）/ 一句话说（单行版本）/ 一个具体的场景是（人+动作+画面）/ 分层披露（一句话版→一段话版→完整版，对方没追问就停在单行）。
- **检验句（表达前/中自审）**：这是事实还是我的推论？/ 讲给完全外行的人我会怎么说？（费曼式）/ 这在什么条件下成立，什么条件下不成立？/ 反过来呢？（芒格式 invert——从修辞升级成思维动作）/ 所以呢？这对我接下来要做的事有什么影响？
- **李笑来三动作**：「我们先定义一下」（概念洁癖）、「这就像……」（类比强制器）、「你一定要意识到」（元认知喊话——Liz 的「你可以想象一下」是其温和版）。

**边界**：这些是 Liz 自己的表达训练，不是脚本创作素材；修整/重建不得把引擎型口癖写进她没说的话。

## 5. 活人感机制（为什么真人交流是最快校准）

- 真人给实时「丢包反馈」（皱眉/走神/「啊？」），当场重传、降速、换协议；AI 永不走神，发射功率一路走高不自知。
- **口播 = 表达系统的压测环境**：线性、一次性、无编辑余地，书写态堆叠全暴露。写文字有编辑环节，口癖会被无意识打散——所以转录文字反复「顺过」会看不见口癖，开口才第一次无滤镜暴露。
- 不同主体 = 不同传输协议；不牺牲思维复杂度，只分场合决定暴露多少层。
