# Landing Page Replication v5 — Skill Pack

Hermes / agent skill for high-fidelity marketing landing replication.

## Install

1. Copy `skill/` into your agent skills directory as `landing-page-replication-v5/`
   (e.g. `~/.hermes/skills/web/landing-page-replication-v5/`).
2. Install script deps: `pip install -r skill/scripts/requirements.txt`
3. Prefer Chromium + Playwright for Loop 0 capture (see `skill/SKILL.md`).

## What you get

- 7-phase pipeline: Capture → Signal → Skeleton → Density → Micro-parity → Behavior → Polish
- Scripts: `capture.py`, `capture-runtime.py`, `audit.py` (`--imr`, `--behavior-offline`, …)
- References: behavior gates, signal sheet, IP/fonts notes, case studies

## Risk posture

Study / internal-only by default. For ship-as-product: composite 3–5 leaders; never copy logos or proprietary imagery.

Not legal advice. See `skill/references/ip-and-fonts.md`.
