# Feedback Pipeline (GitHub + Telegram)

Same-origin Cloudflare Pages feedback widget → GitHub Issues and/or Telegram.

Drop the folder into your agent skills directory. Copy `references/feedback-function.ts` and `references/FeedbackWidget.tsx` into a CF Pages project, set env vars, redeploy.

See `SKILL.md` for the full workflow, anti-SaaS positioning, and verify curls.
